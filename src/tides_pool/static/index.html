  • DATUM: Leo pow_0.4.1_18+ (or experimental MaVeTh _20) — see above.
  • DATUM → pool: pool_host=tides.maveth.ca pool_port=28916 (LAN: NAS IP).
  • Payout: mining.pool_address = your bc1… / 1….
  • Usernames: Pool Pass Full Users = OFF · miners = worker name only (e.g. rig1).
  • Tag: coinbase_tag_secondary = your name; primary is TIDES.
  • Miners: point ASICs at your Gateway stratum — never port 28916.
  • Fallback: keep solo / another pool configured.
